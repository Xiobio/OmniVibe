## 选择

根据实际对比，已选定十套游戏主题与墨玉都以 **C：内框整体外移** 作为后续方向，保留 **B：只留外框** 作为专注模式。墨玉的角饰需与原插画外框融合。A 不再采用。十套 C 的进一步细化见[新版前后对比](../terminal-frame-refinement/index.html)。

| 方案 | 视觉与阅读 | 取舍 |
| --- | --- | --- |
| A 保留内框 | 角饰会与首行、左侧字形相交，形成第二道内容边界 | 不建议保留；移到文字背后也只能改变覆盖顺序，无法消除视觉干扰 |
| B 只留外框 | 只保留外缘细线与流光；墨玉保留已有插画外框 | 阅读最安静，适合长时间编码；部分主题的独有几何角饰会消失 |
| C 内框整体外移 | 保留原主题角饰，扩大边框到窗口外缘留白，包住原文字区域 | 风格辨识度与阅读空间更均衡；插画已有厚框时应减法处理 |

## 第三种方案的范围

所有对比保持文字起点为横向 36、纵向 32；字号、行距、内容与文字区域大小相同，没有缩小可读区域。

A 将原边饰坐标放在文字渲染区域的边缘，造成边框进入字形区域。C 把边框矩形从原文字区域扩大到背景四边各约 2 个单位的外缘，并保留各主题原有角纹尺寸。十套主题的边饰宽度为 24，文字上下仍有约 6、左右约 10 的额外间隔。蓝色与金色的关系见[区域示意](https://raw.githubusercontent.com/Xiobio/OmniVibe/v0.1.1-preview/docs/terminal-frame-comparison/geometry.png)。

## 验证与边界

- 十套主题使用 `skins/catalog.json` 的色板、Terminal 清单中的插画透明度和仓库原插画；墨玉另用现有配色与 0.5 插画透明度。
- 边饰几何从 `themes/windows-terminal/shaders/designs/*.hlsl` 逐套移植为离线绘制，墨玉参考旧 `ornate-frame-v2.hlsl`。不是为十套主题套同一个通用角纹。
- 背景与终端示例文字在 A/B/C 之间完全一致；A 展示旧的文字后处理覆盖位置，B/C 将边饰置于文字下方。
- 66 张预览均完整解码；两个尺寸的全部 B/C 方案，边饰效果与示例字形相交像素为 0；全部 C 外框矩形均包住原文字区域。
- A 在常规窗口的示例字形相交范围为 106–538 像素（十套主题）。该数字仅描述此夹具，不代表真实 Terminal 中所有字号和窗口尺寸的结果。
- 原插画哈希未改变，未操作真实 Terminal 窗口，也未切换当前终端主题。
- 对比页已在 Edge 检查方案切换、主题切换、原尺寸放大、窄窗口筛选和图片加载。

这些是基于实际资源的**离线设计合成图**，不是 Windows Terminal 实机截图，也没有模拟其所有透明度、字形光栅化和 GPU 混合细节。光效统一定格在 8 秒，不能据此判断动画流畅度。决定方案后，仍应按实际背景层实现，再检查真实 Terminal 的多个尺寸与 DPI。
