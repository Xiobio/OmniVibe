# Theme showcase

[← Back to OmniVibe](../../README.en.md) · [简体中文](showcase.md)

**One workspace, your own atmosphere.** Explore all **13 themes: the default Relic theme and 12 alternatives**. Each theme coordinates the task wheel, inventory, and terminal appearance. Click any thumbnail to view the original image.

Choose a built-in style, then use your favorite characters, animals, or custom images as task portraits. Themes change the look and feel; fixed slots, shortcuts, arrangement, and status integration remain the same.

[Default theme](#default--relic-vault) · [Task wheels](#task-wheels--12-more-styles) · [Task inventory](#task-inventory--see-your-workspace) · [Terminal themes](#terminal-themes--carry-the-atmosphere-into-your-work)

## Default · Relic Vault

**Default theme: Black Myth: Wukong · Relic Vault.** A coordinated wheel, task inventory, and terminal appearance. Sound follows the selected theme by default; corresponding audio must be installed locally. Missing audio stays silent, and you can import your own WAV files.

Terminal colors, artwork, and borders can match the theme while keeping the native Windows Terminal title bar. Configuration is backed up before applying changes. Backgrounds are static by default; animation is optional.

## Explore and customize

Right-click the launcher → Settings → Themes & loadouts. Select a theme, then choose task portraits or import your own images. Sound follows the selected theme unless overridden and requires locally available audio.

After downloading the repository, open the [offline interactive gallery (Chinese)](../showcase/index.html) in a browser to switch between all 13 themes and four views: wheel, inventory, loadout, and terminal. GitHub displays the HTML source; download it to use the controls.
