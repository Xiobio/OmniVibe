## 名称与标语

- 产品名：OmniVibe
- 中文标语：管好每一个窗口，让 Vibe Coding 更轻松。
- 英文副标题：The Gamified Task Inventory for Vibe Coding
- 仓库 About 建议：A Windows window manager for parallel AI coding. Organize terminals, switch by hotkey or radial menu, arrange windows, and personalize your workspace with themes.

## 简短介绍

窗口开太多，找不到、切换慢、排版费劲？OmniVibe 将终端收进固定槽位，按编号或轮盘直达任务，用总览集中查看窗口，一键排列后还能恢复原布局。再用喜欢的角色、主题与视听反馈打造个人工作空间。面向多 AI Agent 并行开发，当前为 Windows 开发预览版，自有代码 MIT。

## 完整介绍

让三个 Agent 同时干活之后，你是否开始做另一份工作：反复 Alt + Tab 找窗口，挨个检查进度，再确认哪个任务停在授权提示上？

OmniVibe 给每个终端一个固定的装备槽。前端放 1 号，接口放 2 号，测试放 3 号；Alt + 2 直接进入接口任务。也可以按住 Alt + Q 唤出轮盘，像选择武器一样指向目标、松键切换。平时只保留小巧入口，悬停才展开。

任务总览汇集窗口预览和已接入的状态。13 套主题让圆环、配装、菜单与 Windows Terminal 拥有协调的外观，动画和声音也可以按习惯调整。已有终端与 CLI 继续运行，OmniVibe 为它们提供一个可辨认、可学习的桌面入口。

项目使用 C#、WPF 和 Win32，当前为 Windows 开发预览版。自有代码采用 MIT；第三方素材单独说明来源和许可范围。完整社区皮肤包 SDK 尚在规划中。

## 社交平台文案

同时开三个 AI Agent，最忙的却是自己：找窗口、看进度、找那个停在确认提示上的任务。

所以做了 OmniVibe，把这些终端变成一个桌面任务装备栏。前端放 1 号，接口放 2 号，测试放 3 号；Alt + 数字直接进入，按住 Alt + Q 还能像切换武器一样切任务。接入状态后，打开总览就能集中查看谁在等你。

平时只留一个小巧入口，悬停展开。再给圆盘和终端换上同一套主题，整个工作桌面也终于有了自己的样子。

目前是 Windows 开发预览版，自有代码 MIT。欢迎反馈真实工作中的切换、拖动和多显示器体验。

| 时间 | 画面与操作 | 字幕 / 旁白 |
