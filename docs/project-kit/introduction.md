# 项目介绍

**管好每一个窗口，让 Vibe Coding 更轻松。**

OmniVibe 首先解决多窗口工作中的实际麻烦：窗口散落、互相遮挡，切换时找不到目标，并排查看时需要反复拖动和缩放。它将已有窗口集中绑定到固定槽位，提供编号与轮盘切换、任务总览，以及一键排列和恢复。

在窗口管理基础上，任务可以由喜欢的角色、装备或器物代表，声音、动画与主题也可以调整。工具负责整理窗口，个人喜好赋予工作空间熟悉的形象和游戏趣味。当前支持内置主题、自定义任务图片和视听设置，完整社区皮肤包 SDK 仍在规划中。

前端 Agent 在改页面，接口 Agent 在写代码，测试窗口滚着日志。你明明让任务并行了，自己却开始反复找窗口、看进度、确认谁在等输入。

OmniVibe 给这些独立窗口一个固定位置：前端放 1 号，接口放 2 号，测试放 3 号。`Alt + 2` 直接进入接口任务；按住 `Alt + Q`，还能像选择武器一样指向目标、松键切换。接入 CLI 状态后，总览集中呈现谁在运行、谁需要处理。

[按模块查看主题效果](showcase.md)。

它把“哪个窗口在哪”和“该关注哪个任务”放到一个可视入口里，让你更容易回到实际工作。平时只保留小巧入口，需要时再展开，原来的终端和 AI 工具继续照常使用。

## 产品体验

平时，桌面上只保留小巧的悬浮入口。鼠标移入展开任务，移开收回；需要调整位置时长按左键拖动，管理功能收进右键菜单。可以用鼠标选择，通过编号快捷键直达，也可以使用按住、指向、松开的轮盘交互。

打开任务总览，窗口预览、任务名称和已接入的状态帮助你决定下一步。主题为圆环、配装、总览与终端建立一致的视觉语言；动画、音效和装饰提供可调整的反馈。

## 适合的场景

- 同时运行多个 Claude Code、Codex 或其他终端任务。
- 将编码、测试、服务日志等独立窗口放进固定位置。
- 用装备、器物和主题建立视觉记忆，减少辨认相似窗口标题的负担。
- 个性化桌面，同时保留现有终端和命令行工作流。

## 设计原则

**稳定的位置。** 编号形成可学习的路径，换主题不应改变任务身份。

**克制的常驻界面。** 日常入口紧凑，展开后呈现更多信息，管理操作集中到菜单与设置。

**可解释的状态。** 状态来自接入事件，没有证据时显示未知；长时间没有更新则提示可能过期。

## 实现与范围

当前采用 C#、WPF 和 Win32，运行于 Windows，管理已有的顶层窗口。Terminal 内部标签页和分屏不能分别绑定。项目不内置完整终端解释器，也不替代各 AI 工具的权限与会话机制。

现有 13 套主题、配装图片自定义和外观设置已经形成体验基础；通用社区皮肤包 SDK、跨平台支持不属于当前已交付能力。项目处于开发预览阶段，发行状态以实际 Release 为准。
