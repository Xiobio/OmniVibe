# 常见问题

### 它会替换终端吗？

它管理已有窗口，终端和 AI CLI 各自运行。当前是 Windows 原生应用。

### 两个标签页能分别绑定吗？

不能，管理单位是整个顶层窗口。请先拆成独立窗口。

### 为什么 Tab 补全失效？

默认总览使用全局 Tab。到设置更换或关闭该绑定；自定义单键也可能影响其他应用输入。

### 入口不见了怎么办？

使用 `Ctrl + Alt + Space` 或单击托盘中的仓鼠图标。修改过快捷键时以当前设置为准。

### 为什么状态未知，已回复又不代表完成？

窗口绑定和状态接入独立。检查 CLI hooks、任务关联与事件更新时间；本轮已回复不代表测试通过或需求验收完成，旧状态也可能过期。

### 移出槽位会结束进程吗？

移出管理会解除关联，保留终端。它不同于关闭原窗口。

### 管理员终端为什么可能切换失败？

Windows 权限边界影响跨进程操作。应用不会自动提权，不能保证控制更高权限的窗口。

### 主题会修改 Terminal 什么？

配色、背景和相应原生界面外观，写入前备份。当前应用器保留命令、工作目录、环境变量、字体、字号和快捷键，详见 [统一主题](../unified-themes/README.md)。

### 能自制皮肤或关闭动效吗？

可自定义配装图片、调整音效动画装饰，也可修改源码资源。完整社区皮肤 SDK 与包分发尚未提供。部分标志音需单独安装，缺少时保持静音，见 [音源说明](../../skins/signature-audio/README.md)。

### MIT 覆盖游戏图片和声音吗？

不自动覆盖。自有代码与第三方素材范围见 [素材声明](../../THIRD_PARTY_NOTICES.md)。

### 有跨平台版、安装包和性能保证吗？

当前文档描述 Windows 开发预览版；安装包以实际 Release 为准。历史性能报告是特定环境测量，不代表所有电脑的切换延迟与资源占用。
