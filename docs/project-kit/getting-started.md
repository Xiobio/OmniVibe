# 快速开始

## 准备与启动

需要 Windows 和 .NET 10 SDK，版本基线见 [global.json](../../global.json)。Python 用于部分开发验证与资源工具，日常运行应用不需要执行这些工具。

```powershell
git clone https://github.com/Xiobio/OmniVibe.git
cd OmniVibe
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

克隆需要拥有仓库访问权限。启动脚本编译 Debug 版；已有实例会被请求正常退出。使用自行构建的框架依赖发布包时，需要匹配的 .NET 10 Windows Desktop Runtime；运行 `CodeManager.exe` 并保留随包资源目录。

## 第一个任务

1. 打开一个终端窗口，运行开发任务。
2. 点击空槽选择窗口，或将窗口标题栏拖入悬浮入口。
3. 为任务选择容易辨认的名称和配装。
4. 使用编号快捷键进入任务。

一个窗口占一个槽位。希望两个 Terminal 标签页分别切换时，先将它们放进独立窗口。移出管理不等于关闭终端。

## 日常操作

| 操作 | 默认行为 |
| --- | --- |
| 悬停入口 / 移开 | 展开 / 收起 |
| 长按左键拖动 | 移动入口 |
| 右键入口 | 管理菜单 |
| `Alt + 1–9` | 切换固定槽位，再次按下恢复先前窗口状态 |
| `Alt + 滚轮` | 切换任务 |
| 按住 `Alt + Q` | 显示轮盘，指向后松键进入 |
| `Tab` | 打开 / 关闭总览 |
| 总览中滚轮、Enter | 选择、进入 |
| `Alt + 反引号` | 排列 / 恢复窗口 |
| `Ctrl + Alt + Space` | 显示 / 隐藏入口 |
| 左键单击托盘图标 | 显示 / 隐藏悬浮入口 |

以个人设置为准。**全局 Tab 会影响终端补全**，可关闭或改键。快速上手显示实际保存的快捷键；隐藏后单击托盘中的仓鼠图标可找回入口。

## 主题与声音

「设置 → 主题与换装」选择主题并保存应用。统一主题同步管理器界面与可用的 Windows Terminal 配置，写入前备份；没有 Terminal 配置时提示仅保存管理器外观。

背景默认静态，动态背景独立选择。界面动画、音效与装饰可调整。预览或取消不会应用 Terminal 配置。详见 [统一主题](../unified-themes/README.md) 与 [Terminal 恢复说明](../terminal-skins.md)。

## 状态接入

绑定即可收纳和切换。窗口标题与本地 CLI 会话能够唯一对应时，会自动关联状态；无法自动对应时，右键任务 →「连接当前 CLI 会话状态…」，选择正在使用的会话，无需重启 CLI。需要精确的权限确认等事件时，再按 [详细指南](../usage.md) 配置 hooks，并用一次运行及等待确认验证关联。

未知表示缺少有效信息，本轮已回复仅表示该轮有回复；长时间无更新会提示状态可能过期。最终结果仍需查看终端。

## 退出与恢复

正常退出管理器会恢复其收起的窗口，CLI 继续运行。窗口重建后可能需要重新关联；恢复工作现场依赖保存的任务配置，不能保证恢复任意 CLI 的完整上下文。

状态目录为 `%LOCALAPPDATA%\CodeManager`。迁移或修改前先备份；分享诊断信息前删除私人路径、窗口标题、会话标识和密钥。
