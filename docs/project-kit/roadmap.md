# 路线图

区分现有能力与未来方向，不承诺发布日期。

## 当前基础

- 固定槽位、悬浮入口、轮盘、总览与可配置快捷键。
- 窗口绑定、切换、排列、重连与配置恢复。
- 支持的 CLI 状态事件接入及过期提示。
- 13 套主题、配装图片与外观开关。
- Terminal 外观同步、配置备份与静态 / 动态背景。
- 可靠性验证、资源清单与精简发布脚本。

## 优先打磨

1. 拖动、悬停边界、菜单关闭、焦点与输入冲突的稳定性。
2. 键盘导航、缩放、减少动画与对比度等可访问性。
3. 断连、旧事件和任务关联的状态诊断。
4. 可重复构建、版本对应证据、素材核查与安装体验。

## 后续探索

- 稳定的皮肤清单、校验规则、导入和示例包。
- 社区制作指南与来源、许可元数据。
- 更多 CLI 状态适配。
- 多显示器与高 DPI 自动回归。

跨平台、完整终端模拟器和任意 Agent 自动控制目前没有承诺。
