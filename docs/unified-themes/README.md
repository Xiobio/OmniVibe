# 整套主题与经典皮肤补全

设置 → 主题与换装 → 选择主题图片 → 保存并应用。

一次保存同步 OmniVibe 圆环、槽位、任务总览、菜单和 Windows Terminal 顶部、正文配色、插画与外框。应用器覆盖各 profile 的独立外观及失焦外观，保留命令、工作目录、环境变量、字体、字号和快捷键；每次写入前备份原始配置。失败会显示错误并保留设置草稿。预览、取消不会应用 Terminal。

Terminal 背景动画是独立选项，13 套均可勾选，选择会保存并在重新打开设置后恢复。默认静态；开启使用 GIF，关闭切回 PNG。主题预览和实际应用使用同一套资源。没有 Windows Terminal 配置的设备会明确提示仅保存 OmniVibe 外观。

三套经典主题均有独立新插画、原生界面场景、精修 C 布局外框、静态/动态插画版和静态/动态纯边框版。所有背景位于 Terminal 正文之下，边饰留在安全外缘，不重新加入正文内框。

| 主题 | 场景 | 边饰 |
| --- | --- | --- |
| 墨玉机关 | 松鹤山水、青铜浑仪与玉石 | 云雷纹、玉石嵌件、青铜回纹 |
| 玄夜青金 | 月下海山、星仪与云龙 | 月牙、星轨、青金嵌件 |
| 朱砂藏锋 | 漆红宫阙、凤凰剑匣与铜香炉 | 羽纹、漆木、铜金锋刃 |

插画由内置 imagegen 原创生成，文件与完整提示词在 `skins/ink-jade`、`skins/midnight`、`skins/cinnabar`。框线、材质、外缘动效由既有程序化构建器生成；原始插画不被修改。三套 Terminal 的全部 ANSI 色经过逐像素对比度校准，动效只改变外缘，阅读区保持静止。

空槽代表物使用独立原创透明素材，不显示游戏名称、官方 Logo 或任意任务的当前配装。具体素材与提示词见 `skins/identities`。

验证记录和实际设置应用证据见本目录 `validation.json`。未打包。
