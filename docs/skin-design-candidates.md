# OmniVibe 游戏风格皮肤候选

本文整理面向中国大陆玩家的 10 套游戏风格皮肤候选，包括视觉方向、任务栏与总览的表现、统一状态规则和建议制作顺序。

名单用于设计参考，顺序不代表游戏热度排名。十套方向现已实现为原生界面与配套 Terminal 套装；下文保留最初设计约定与范围。最新[完整配装实拍](game-suite-refinement/index.html)覆盖十套游戏及三套经典主题，每套九个独立实体；[音效试听](game-audio/index.html)覆盖每套十四种操作。界面材质、插画与音效采用原创实现；角色素材与原创风格演绎的来源分别记录在[内容包规范](../skins/loadouts/suites-v1/README.md)，不将原创演绎称作官方皮肤。

相关文档：[产品定义](product-definition.md)、[使用与开发指南](usage.md)。

## 设计约定

- 以游戏的交互和视觉语言作为灵感，图标、纹理、装饰与音效采用原创素材。
- 所有皮肤共用任务数据、槽位编号、操作接口和状态含义。
- 皮肤应形成完整的视觉风格差异，覆盖材质、形状、字体、图标、动效和声音。
- 动画、音效与装饰可关闭；关闭后仍能清楚识别任务和状态。
- 切换皮肤时，任务绑定、槽位编号和窗口状态保持不变。
- 窗口操作立即执行，视觉与声音反馈不延迟切换。

## 统一状态规则

| 状态 | 必须保留的信息 | 可自由设计的表现 |
| --- | --- | --- |
| 运行中 | 状态文字与图标 | 能量流、微光、指示灯 |
| 等待处理 | 明确的人工处理提示 | 呼吸边框、符印、警示标记 |
| 本轮已回复 | 回复完成与未读标记 | 印章、信封、完成图标 |
| 错误 | 错误文字与标记 | 红色边缘、短促震动或故障效果 |
| 未知 | 明确显示“状态未知” | 中性边框、空心指示灯 |
| 窗口断开 | 独立的断连标记 | 熄灭的装置、断开的连接线 |

窗口连接状态独立于任务执行状态。窗口断开不直接表示任务报错，“本轮已回复”也不表示整个开发任务已经完成。

状态通过文字、图标与颜色共同表达。未读提示、当前选中任务和执行状态分别展示，避免混淆。提醒不抢焦点，不改变槽位位置。

## 建议制作顺序

### 1. 三角洲行动 · 战术终端

参考《三角洲行动》，优先作为现有水墨主题之外的第二套皮肤。

现代军事科技风与水墨主题差异明显，适合检验完整换肤能力。侧栏设计成九个设备接口，总览设计成战术监控屏，重点完成接入、切换、等待授权和断开连接的反馈。

### 2. 永劫无间 · 无间兵器匣

参考《永劫无间》，突出装备收纳、固定槽位和快速切换之间的对应关系。

使用玄铁、古铜、暗红与兵器架结构，任务以装备位置呈现，状态通过符印和边缘光表达。通过金属材质和紧凑结构，与现有水墨卷轴主题形成区别。

### 3. 黑神话：悟空 · 灵蕴法宝匣

参考《黑神话：悟空》，突出东方神话的器物质感。

以石刻、雕饰、旧金属和深色面板构成视觉主体。侧栏采用法宝龛位，总览采用器物图录结构，避免沿用现有主题的宣纸卷轴与木纹表现。

## 单套皮肤的初期设计范围

先完成右侧任务栏、九宫格总览、五种任务执行状态、空槽、选中、未读与窗口断开状态，再统一设置页和弹窗。

验收重点：编号易于辨认，任务名称与状态清晰，窗口预览可用，切换立即响应；关闭动画和声音后仍可正常操作；换肤后原有任务绑定、槽位与状态不变。
