# OmniVibe 使用与开发指南

> 当前程序和源码目录仍使用 CodeManager 名称。本文命令均在项目根目录执行。

Windows 本地开发版，使用 C# / WPF / Win32。把已有 terminal 窗口收录到右侧固定槽位，通过快捷键切换、排列，并查看 Claude Code / Codex hooks 发来的状态。

主界面是常驻桌面的装备入口，直接替代纵向侧栏。中心显示当前角色、武器或藏品，不再用终端名称的首字作身份。鼠标移上去展开装备槽，点击已连接任务立即切换；悬停任务会立即显示轻量文字详情，不另开预览大窗。收起后的实际窗口为 116×116 DIP，展开时才临时分配任务区域。核心位置不变，悬停不激活窗口、不占用终端键盘焦点；长按拖动时按画面刷新更新位置，松手才保存。

离开整个轮盘操作范围约 400–425 毫秒后开始收回；经过透明空隙会保持展开，短暂移出再返回会取消收回。点击核心保持展开；左键长按约 200 毫秒进入移动，也可按下后直接拖动，松手保存位置。移动入口不会激活任务，Esc 可结束拖动。01–09 的角度固定，01 在正上方；任务与配装跟随稳定 ID，重排后按新的数字位置切换。空槽常态显示淡加号。悬停空槽不会替换中心装备。

展开后点击空槽可选择窗口；拖动外部窗口靠近核心会自动展开，拖到空槽松手绑定，拖到中心会选择第一个空槽。右键核心显示添加窗口、任务总览、排列/恢复布局、设置与皮肤、更多五个入口；少用操作收进「更多」。点击菜单的 ×、按 Esc、再次右键圆环或点击菜单外部都可关闭。右键任务保留编辑、状态、恢复和移出等操作，其余操作收进「更多任务操作」。动画、装饰、音效可分别关闭，关闭动画后展开与收回立即完成。

13 套主题各有九个独立透明实体：海克斯兵器、战术枪械、特工、冒险装备、永劫角色、灵蕴法宝、星曜武器、棋灵、元素器物与三界角色等。槽位、临时轮盘、总览与设置预览使用同一套内容，编号、状态与任务详情独立展示。

总览保留实时终端缩略图、任务名与状态，边框和装饰跟随主题。短屏幕会提供滚动，插画不会撑大卡片或遮住文字；只为完整可见的预览区域显示原生缩略图。动效在窗口操作后反馈，不等待播放结束。材质、装饰和音效可分别关闭，运行时不依赖在线素材。

目前只编译和运行 Debug 开发版，不生成安装包或发布压缩包。旧的 artifacts/CodeManager 是早期版本，不随源码更新。

## 启动

需要 .NET 10 SDK 和 Windows Desktop Runtime。在项目目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

脚本会请求开发版正常退出、编译 Debug 并重新打开。旧版不支持自动退出时，需先从托盘菜单退出。退出背包会恢复它收起的窗口，终端里的 CLI 继续运行。

开发程序：src/CodeManager/bin/Debug/net10.0-windows/CodeManager.exe。

## 收录和管理

1. 拖动窗口标题栏靠近右侧，背包会展开全部槽位。空槽变绿时松手收录。
2. 默认最小化原窗口，后台任务继续运行。已占用槽位显示阻止提示，不会被替换。
3. 按 Alt+编号唤出对应窗口，也可点击卡片。
4. 右键卡片编辑名称、颜色、项目目录，或连接 CLI 状态。

点击空槽可选择已有窗口。绑定单位是整个窗口，不能单独绑定 Windows Terminal 内部标签页或分屏。

编号固定为 1–9。悬停展开后，空槽常态显示「＋」，左键直接添加窗口。关闭窗口后自动腾出槽位，项目、会话与配装保存到「最近关闭」（最多 30 条）。从「更多 → 最近关闭 / 恢复工作现场」重新恢复，使用空槽并保留原任务 ID。

右键任务扇区可移出管理，也可按住已占用扇区拖出轮盘窗口边界至少 28 像素后松手；终端窗口保留并恢复，不结束 CLI。拖到另一个扇区上松手可主动调整顺序，编号重新按 1–9 排列，任务 ID、状态事件和恢复快照随任务保留。拖动中按 Esc 或返回原扇区松手取消。

左键长按圆环直接拖到目标位置，松手自动保存；不需要先打开菜单或按修饰键。右键圆环打开管理菜单，也保留「移动圆环」入口。大小通过右键「设置」调整，位置和尺寸自动保存；菜单可恢复右侧贴边与自动高度。靠近自由放置的圆环也可拖入收纳。

## 默认快捷键

| 按键 | 动作 |
| --- | --- |
| Tab | 打开 / 关闭独立任务总览 |
| Alt+Q（按住） | 打开任务轮盘；指向已连接任务后松开 Q 或修饰键切换 |
| Alt+1–9 | 唤出对应任务；再按同一编号恢复唤出前的状态 |
| Alt+滚轮 | 每滚动一格立即切换窗口，无中间画面 |
| Alt+反引号 | 立即全部排列；再次触发恢复原布局 |
| Esc | 关闭任务总览 |
| Ctrl+Alt+空格 | 显示 / 隐藏背包的备用组合键 |

常驻轮盘可直接点击扇区进入任务，不必先打开其他界面。另保留 Alt+Q 临时放大轮盘：按住组合键，在鼠标附近展开，移动到已连接任务后松键进入；中央、轮盘外、空槽和断开的任务均取消，Esc / 右键也可取消。托盘“打开任务轮盘”使用临时放大轮盘的点击确认模式。临时轮盘打开与浏览不移动任务窗口，也不夺走终端键盘焦点；切到其他应用会取消。可在设置中更改组合键。

海克斯皮肤使用原创矢量信号：箭头代表运行、金色感叹号代表等待、红色感叹号代表错误、勾代表本轮已回复、圆点代表未知。选择时出现方向光束与扩散环，装备后有短暂信号反馈。所有信号读取真实任务状态；本轮已回复不等于整个任务完成。关闭动效后保留轮盘选择与静态状态标记。

按一下 Tab 打开任务总览，不必持续按住 Alt：普通滚轮或方向键浏览，Enter / 点击进入，1–9 直接进入对应槽位。Tab / Esc 关闭并回到原窗口，点击其他应用也会关闭。打开总览不移动、排列或最小化任务窗口；只有进入任务时才唤出窗口。右侧栏仍由 Ctrl+Alt+空格控制显隐。

**Tab 默认全局接管**，会替代终端 Tab 补全和应用 Tab 导航。可在“设置”关闭；“暂停快捷键”和打开本工具对话框时会让出 Tab。Shift+Tab、Ctrl+Tab 等组合保持原用途。关闭总览不会关闭任务窗口。

设置分为主题套装、声音与反馈、圆环与位置、窗口与排列、快捷键、常规与状态六页。可更改数字键和鼠标手势修饰键、总览键、排列键和入口显示键。总览允许单独 Tab，其余使用组合键；保存时检查重复。只有已连接槽位注册数字快捷键；没有可切换任务或已暂停时，鼠标手势交还原应用。冲突会显示提示。备用显示键冲突时依次尝试 Ctrl+Alt+Shift+空格、Ctrl+Alt+Shift+D；也可双击托盘恢复入口。

排列支持均衡网格、纵向分栏、横向分行、主窗居左；间距默认 0，排列和恢复时保留悬浮入口。外观提供十套游戏与三套经典主题，以及展开范围、位置、自动收起、收纳后最小化、动画和声音设置。

在「主题套装」选择主题后，可打开对应配装页。内置藏品按主题分别保存，选择一套不会改变另一套；自定义图片随任务跨主题保留。配装使用独立草稿，取消不会改动；来源、原创演绎说明与素材规格见[内容包规范](../skins/loadouts/suites-v1/README.md)。

「声音与反馈」只在成功切换窗口时播放一个游戏标志音。默认跟随界面主题，也可单独选择声音主题，按「保存并应用」后持久生效；切换设置页面不会重置选择。可试听、调整音量，或导入自己的 PCM16 WAV（0.01–3 秒、单声道或立体声、16–96 kHz）。导入与恢复先进入草稿，保存失败回滚本轮文件更改，取消保留原声音。真实游戏标志音单独安装，未安装时明确提示并保持静音，不会改用早期合成音。来源及安装见[主题标志音](../skins/signature-audio/README.md)。

## 窗口和提醒

- 可选择恢复最近工作位置，或统一放到背包所在屏幕工作区。
- Alt+反引号或菜单排列操作直接铺满屏幕工作区，不预留空白，不留网格空洞；系统任务栏保留。排列和恢复时入口都保留，只有主动隐藏才消失；Tab 背包仍可使用。
- 再按排列键还原排列前的位置和最小化状态；只管理收录窗口。
- 排列中按 Alt+数字会单独放大该任务，不撤销整套排列；再按同一编号回到原格子。切换到其他编号会先还原上一个临时唤出的窗口。
- 普通状态下再次按同一编号，会恢复唤出前的位置、大小和最小化状态。Tab 卡片和滚轮始终用于进入任务，不会因重复选择而收回。
- 支持常驻、自动收起、完全隐藏；收起后保留当前装备入口。
- 当前窗口、滚轮选中项和未读提醒分别显示。等待、回复、错误会提醒，唤出窗口清除未读标记。
- 提醒不抢焦点，不重新排序。悬停立即显示任务详情；总览提供窗口预览，最小化窗口的缩略图可能停止更新。
- 显示器布局变化后调整背包位置，唤出时将已离屏窗口校正到可见区域。

## 连接 Claude Code / Codex 状态

右键任务 → 连接相应 CLI 状态 → 复制命令，在该窗口的终端执行。若 CLI 已运行，先正常退出 CLI，再执行接入命令；恢复旧会话可使用 CLI 自带功能。接入只作用于这次启动，不改全局配置。

Codex 首次提示 hooks 待审核时，在 /hooks 查看并信任观察脚本。脚本只写本地状态事件，不批准操作、不添加模型指令。未接入时显示“状态未知”，不会根据终端输出频率猜测是否完成。

| 生命周期事件 | 背包状态 |
| --- | --- |
| 提交提示、工具返回、输入回复 | 正在执行 |
| 权限请求、请求用户输入 | 等待我处理 |
| 本轮停止 | 本轮已回复 |
| Claude StopFailure | 发生错误 |
| 会话结束 / 中断 | 状态未知，附结束 / 中断说明 |

忽略子代理事件和普通闲置提醒。未手动命名时可用首行提示摘要作为名称；项目目录来自 hooks 的 cwd。

启动器和事件映射已做本机验证。实际交互仍需要在各自 CLI 会话中接入并验证，CLI 升级可能改变事件支持。Codex 启动器支持原生 exe 和标准 npm 安装。

参考：[Claude Code hooks](https://code.claude.com/docs/en/hooks)、[Codex hooks](https://learn.chatgpt.com/docs/hooks)。

也可手动设置状态，或供其他工具调用：

```powershell
.\scripts\Set-TaskStatus.ps1 -Slot 1 -State running
.\scripts\Set-TaskStatus.ps1 -Slot 1 -State waiting -Message '需要确认操作'
.\scripts\Set-TaskStatus.ps1 -Slot 1 -State ready -Message '本轮回复结束'
```

长期运行的会话应固定使用任务 ID。背包约每 500ms 处理事件，重连或删除的任务不会接收旧 ID 的事件。两个接入脚本随 Debug 编译复制到程序旁的 scripts 目录。

## 数据和恢复

圆环右键菜单或系统托盘 → **恢复上次工作现场**，查看上次任务的名称、项目、最后在线时间、状态和备忘。支持单独恢复、批量恢复已配置任务、匹配已有窗口，以及手动选择窗口。

每个任务的“配置恢复”中可选择项目终端（PowerShell）、Claude Code 或 Codex，填写项目目录和备忘。AI 任务可恢复指定会话，也可选择新建会话。接入 hooks 后，项目目录、会话 UUID 和 CLI 类型自动记录；标题与在线时间定期保存。旧任务只有窗口标题时，需补充启动信息，不从标题推断命令或猜测最近一次对话。

新终端优先通过 Windows Terminal 独立窗口启动，缺少 Terminal 时使用 PowerShell。启动后先以随机标记确认窗口、绑定原任务 ID，再启动 CLI 和会话 hooks；重复点击不会反复打开。仅在标题和进程类型一致、没有同名歧义且未被其他任务使用时重连现有窗口；普通终端标题需手动选择。

设置 → 常规与状态，提供“启动时显示未恢复任务”“自动重连已有窗口”“自动打开已配置任务”。默认显示恢复清单并尝试重连，自动新开窗口需自行开启。恢复不会自动提交提示词；AI 的登录、信任和审批仍按 CLI 正常流程进行。恢复项目终端不等于恢复内存、未保存输入或任意后台命令。

Codex 指定会话使用官方 [`codex resume SESSION_ID`](https://learn.chatgpt.com/docs/developer-commands?surface=cli#codex-resume)，Claude 使用本机 CLI 支持的 `--resume SESSION_ID`；不使用“最近一次会话”替代缺失 ID。

数据位于 %LOCALAPPDATA%/CodeManager：tasks.json 保存任务、窗口身份、布局、临时唤出前的恢复快照、设置和状态；events 为事件队列，sessions 为会话配置；app.log 和 bridge-errors.log 记录错误。

hooks 接收 CLI 事件输入，只提取状态、会话 ID、项目目录和可选名称摘要，不保存完整提示或终端会话，不上传数据。

重启后按窗口句柄、进程 ID 和启动时间重新关联。退出只恢复由本工具收起的窗口，不退出 CLI。窗口始终可从系统任务栏找回。损坏配置会先保留恢复副本。

普通权限无法保证控制管理员窗口；失败时会提示，程序不自动提权。

## 开发检查

永劫无间主题支持[高清透明角色配装](character-loadout/README.md)：右键槽位更换角色，或从设置主题页进入。可导入自己的角色、皮肤与武器图；保存后随任务移动和重排，取消不修改当前配装。

```powershell
dotnet build .\src\CodeManager\CodeManager.csproj -c Debug
$app = (Resolve-Path '.\src\CodeManager\bin\Debug\net10.0-windows\CodeManager.exe').Path
$test = Start-Process $app -ArgumentList '--self-test artifacts\dev-self-test.json' -Wait -PassThru -WindowStyle Hidden
$test.ExitCode
Get-Content .\artifacts\dev-self-test.json -Raw | ConvertFrom-Json
```

自检覆盖固定槽位、鼠标手势、Tab 总览与进入窗口、滚轮立即切换、快捷键暂停、设置持久化、显示器边界、Win32 生命周期、DWM 预览、重连隔离、布局恢复、真实 PowerShell Unicode 事件传输。窗口操作只使用测试创建的临时窗口。

`--wheel-benchmark artifacts/wheel-drawing.json` 用九个示例任务测量动画过程的 UI 线程绘制记录耗时和内存分配。结果不包含桌面合成、系统窗口激活与截图编码，不能直接作为实际显示帧率。装备核心复用文字与徽记绘制资源；重复展开/收回保持当前转场，反向操作从当前显示位置继续。拖动圆环与展开/收回转场期间暂停后台窗口检查和磁盘轮询，交互结束后恢复。

还覆盖“排列 → 恢复 → 数字唤出”、已有焦点但被无激活窗口盖住时的重新置前、九宫卷轴缩略图注册，以及合卷时遮罩和缩略图的释放。

--preview artifacts/preview.png 生成示例图；末尾可选 inventory、compact、mini、expanded、settings、task、integration 或 recovery。

恢复检查另覆盖会话与备忘持久化、同名窗口歧义、重复点击抑制、窗口随机标记握手、任务 ID 保留、恢复超时和指定会话参数传递。`--recovery-smoke artifacts/recovery-smoke.json` 会打开一个隔离的空项目终端，验证真实恢复后只关闭测试窗口，不启动 AI 或操作已有终端。
