## 插画与文字

左侧阅读区加遮光层，右侧保留更多插画细节。背景明度按实际正文色和全部 16 个 ANSI 色逐像素约束；最终 GIF 解码后再次测量，而非只验证配色定义。

固定插画采用一次性抖色保留渐变；插画、材质和流光分配独立的调色板预算，避免边框亮色进入正文背景。所有动画帧复用同一份底图，不重新抖色，中央区域逐帧保持一致。

## 实际资源与应用

- 十套带插画 GIF、十套无插画边框 GIF；每套 96 帧，100 ms / 帧，9.6 秒无限循环。
- 对应的静态 PNG，可关闭动画；关闭插画时仍可单独保留边框动画，两者都关闭则仅应用配色。
- `Apply-Skin.ps1` 已接入这些资源，移除后处理着色器；边饰在 Terminal 的背景层，不参与字形后处理。
- 安装文件名包含内容哈希，修订后会获得新资源路径，避免已有标签页继续使用旧缓存。
- 根据当前显示器的逻辑尺寸计算保护留白，至少左右 36、上下 32 DIP；在大屏上可能增加留白。字体与字号不变，但可用列数可能略减。改变显示器配置后需重新应用；跨屏超宽窗口需另行校准。

资源目录：[refined-v1](../../themes/windows-terminal/assets/refined-v1/)。构建入口：[build-refined-terminal-frames.py](../../tools/build-refined-terminal-frames.py)；矢量与材质源：[terminal_frame_materials.py](../../tools/terminal_frame_materials.py)。使用方法见[十套 Terminal 皮肤说明](../terminal-skins.md)。
