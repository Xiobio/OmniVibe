# 项目目录与体积整理（2026-10-20）

此前提到的“400 多 MB”是约 **403.3 MB / 384.6 MiB 的版本化文件工作树**，不含 `.git` 和本地构建缓存。本次检查发现，实际占用更大的来源是多轮开发、验收留下的独立构建副本。

## 主要目录

| 目录 | 整理前版本化文件体积 | 用途与处理 |
| --- | ---: | --- |
| `docs/` | 176.9 MiB | 以截图、对照图和验收图册为主；保留 |
| `skins/` | 129.9 MiB | 当前主题、117 张配装图、兼容人物图与音效；保留 |
| `themes/` | 53.4 MiB | 终端背景、动画与配置脚本；源文件保留，发行时过滤旧版本 |
| `assets/` | 23.4 MiB | 品牌素材；移除旧版重复 ZIP，保留新版 ZIP、图标及源素材 |
| 源码、脚本和其他文件 | 小于 1 MiB | 程序逻辑本身体积很小 |

没有发现值得大规模去重的完全相同文件：大于 50 KB 的版本化文件中，仅一对截图内容相同，节省不到 0.1 MiB。大量图片是不同主题、尺寸或方案的真实变体，不宜按文件名当作重复文件删除。

## 已完成的精简

| 项目 | 结果 |
| --- | --- |
| 本地生成物 | 删除 59 个可再生成目录，合计 6,361,681,096 字节，约 5.9 GiB |
| 工具目录 | 从约 1.3 GiB 降至约 0.5 MiB，主要清理工具 `bin` / `obj` |
| 版本化文件工作树 | 移除旧版 `assets/brand/OmniVibe-brand-kit.zip`，减少约 10.2 MiB；其余旧素材与 Git 历史保留 |
| 精简程序目录 | 从约 184.3 MiB 降至 151.8 MiB，减少约 17.6% |

删除量是清理操作的总量；随后为验证生成了新的发布目录、编译输出和隔离测试数据，因此磁盘净减少量会略小。清理明细和验证摘要见 [证据](reviews/2026-10-20-storage-evidence.json)。

当前运行的 Debug 目录、最新验收构建、巡检状态、源代码、配置和测试报告均保留。没有清空整个 `artifacts/`，也没有整理或改写 `.git`。新版品牌 ZIP 仍在原位置供预览页下载；旧版 ZIP 已加入忽略规则，可通过原生成器重建，也能从 Git 历史恢复。

## 精简发布保留的功能

通过 `RuntimeAssetsOnly=true` 排除十张生成中间图、旧 v3/v4 终端背景、提示词、验证记录和测试/构建脚本。开发构建保持原样。保留所有当前主题、配装及兼容图片、静态与可选动画背景、接入脚本、JSON 配置和音效授权说明。

发布的是依赖 .NET 10 Desktop Runtime 的 Windows 程序目录，不是自包含安装包。缩减来自移除发行时不使用的文件，没有降低图片分辨率或重新压缩当前视觉素材。

验证包括精简包完整自检 45/45、配装验证 12/12，以及使用精简包内脚本和素材执行的终端外观测试；后者只操作隔离配置。测试辅助脚本和用于配色对照的源码只临时放入测试环境，之后移除，未带进最终包。

工具的保护范围与限制见 [维护说明](../tools/maintenance/README.md)。

如果继续压缩源码工作树，主要空间在文档图册：仅 `terminal-frame-refinement` 与 `terminal-frame-comparison` 就约 116 MiB。其中一部分仍是生成器输入、对比记录和图册链接的目标，本轮保留。后续可将展示图册作为独立附件发布，同时调整生成器和链接。

移除工作树中的大文件不等于立即缩小历史克隆体积：已有文件仍在 Git 历史中。本轮没有进行历史重写。
