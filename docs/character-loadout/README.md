# 永劫无间 · 高清透明角色配装

本页保留透明立绘版本的设计记录。当前交互已更新为[空槽加号、即时提示与最近关闭](../interaction-ux/README.md)，空槽在展开后常态可见。

2026-10-19：替代上一版低分辨率武器图与圆形底座。

常驻部分仅绘制角色及手持武器，去掉圆圈、底板、边框、光环和常驻名称。角色名称、任务名、项目目录和 AI 状态通过悬停查看。角色图以原始分辨率载入，并使用高质量缩小渲染。

展开后只显示已绑定任务的角色和小编号。没有任务的槽位不显示、不接住误点；拖入窗口时临时显示编号与「＋」落点。已有任务保留固定位置和编号。断开的历史任务仍显示，方便重连。

九张素材均为 **1024 × 1536、带真实 Alpha 的 PNG**，包括宁红夜、妖刀姬、无尘、岳山、顾清寒、土御门胡桃、殷紫萍、季莹莹、崔三娘。

这些是基于[官方角色原画](https://www.narakathegame.com/)制作的 AI 编辑衍生素材，并非未经修改的官方原始立绘。每张对应的原图地址保留在清单中，原角色权利归原权利人所有。

旧配装 ID、用户导入的图片、任务 ID 和窗口绑定均保留。旧武器小图只作为新素材缺失时的明确回退。配装入口改为右键槽位 →「更换角色 / 配装…」；圆环「更多」及设置主题页也可打开。

本轮检查覆盖高清素材与透明通道、隐藏空槽的点击穿透、拖入落点、固定编号、常驻边界、旧配置与自定义图片、原有窗口操作及设置预览。开发版刷新，不打包。
