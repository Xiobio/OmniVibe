# 永劫无间 · 武器配装

本页保留第一版效果。当前版本已更新为[高清透明角色配装](../character-loadout/README.md)，并默认隐藏空槽。

圆环和槽位使用真实武器图识别任务。第一套内置配装包含太刀、阔刀、长剑、长枪、匕首、棍、弓、双刀、双戟。

- 常驻圆环：当前任务对应的武器图和武器名；悬停其他槽位不会替换当前装备。
- 展开槽位：武器图、快捷键编号、小状态标记。空槽显示半亮武器和添加标记，方便按熟悉的位置收纳。
- 悬停：查看任务名、项目目录、AI 状态和接入情况。状态仍来自原有真实事件接入。
- 配装入口：右键任一槽位 →「更换武器 / 配装…」；或圆环菜单 →「更多」→「我的武器配装…」。设置的主题页也有入口。
- 自定义：可以导入 PNG / JPG / BMP，用自己的英雄、皮肤或武器图；透明 PNG 更适合小尺寸。图片复制到 `%LOCALAPPDATA%/CodeManager/Loadout`，修改或删除原文件不影响已导入的配装。
- 保存：配装独立保存。取消只丢弃本次选择；从设置打开配装并保存后，取消设置不会撤销已保存的配装。

配装跟随任务调整顺序和移动；移出任务后保留空槽的武器预设。旧配置首次读取时补齐九件默认武器，不改变任务 ID、窗口绑定和快捷键。自定义图片丢失或损坏时回退到内置武器并在配装页提示。

[原生界面预览](index.html)包含 116 DIP 常驻圆环、320/360/480 DIP 展开尺寸、九件装备、配装页和任务轮盘。这些图由实际 WPF 控件渲染；任务内容为测试样例。

当前只有永劫无间主题切换为这套武器身份展示；其他主题保持现有实现。英雄联盟、黑神话及枪械游戏的内置藏品尚未制作，可以先通过自定义图片使用。

素材来自[《永劫无间》官方武器指南](https://www.narakathegame.com/guide/weapon/)，原始透明图片未重绘或改色。各文件源地址、原始尺寸和 SHA-256 记录在 [素材清单](../../skins/loadouts/naraka/catalog.json)，权利归原权利人所有。

验证命令：

```powershell
CodeManager.exe --loadout-test artifacts/weapon-loadout/tests/report.json
CodeManager.exe --self-test artifacts/weapon-loadout/self-test.json
```

不打包；开发运行方式仍为仓库根目录的 `run.ps1`。
