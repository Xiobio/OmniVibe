九件真实武器

以下是分别装备九件武器时的实际常驻圆环。素材来自官方武器指南，保留原有颜色与轮廓。

每个窗口，独立配装

右键槽位 →「更换武器 / 配装…」。选择内置武器，或导入自己的角色、皮肤和武器图。按「保存配装」后生效；取消保留原配置。

任务轮盘

指向武器后，底部显示对应任务和状态。原有快捷键保持不变。

小窗口与自定义图片

内容可滚动，保存和取消始终固定在底部。导入图片复制到配置目录，任务重排与重启后仍保留配装。
