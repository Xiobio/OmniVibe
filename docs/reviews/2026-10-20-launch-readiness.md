4. **远程 CI：** 工作流已补齐，本地通过不代表 GitHub Actions 已成功运行；需要推送后确认。
5. **正式版本与发布范围：** 当前候选仅用于本地审查，不是正式 tag、签名发行或公开下载承诺。
