# 可靠性与轮盘响应优化（2026-10-20）

这是对 [完整代码评测](2026-10-19-code-review.md) 中可直接修复项的后续记录。此前的评测和证据保留为历史快照。本轮保留另一开发任务提交的标志音实现，未重启用户管理器或终端。

## 已完成

1. **配置容错**：修复窗口标题、进程名和任务文本为 JSON `null` 时的异常；同样处理最近关闭任务、排列记录和临时唤出记录中的窗口信息。可修复配置保留任务 ID、窗口句柄和其他字段，并先备份原文件；无法恢复的槽位结构仍先备份，再回退到九个空槽。重连入口也单独防御空标题。
2. **后台事件读取**：目录枚举、时间筛选、读取、解析、隔离损坏文件及确认后的删除均在后台执行。选择最旧的 24 个文件时采用有界堆，不在内存中排序整个目录。界面线程只应用本批状态并保存一次；同一时间只运行一轮读取/应用/确认，保存失败保留事件，之后重试。
3. **状态时效提示**：接入的 Running / Waiting 状态超过 10 分钟没有新事件时显示“状态可能过期”，悬停详情显示最近更新时间，状态色转为未知色，停止运行微光。收到新事件后自动恢复。保留原状态、未读标志和接入信息；不将超时当作 Error 或断线。手动标记、Ready、Error、Unknown 不套用这一时效推断。Hooks 没有心跳，因此这只是信息时效提示。
4. **轮盘图片预热**：先在后台预热当前主题和配装，使用冻结的位图跨线程传递；界面绘制只读缓存，图片就绪后逐步重绘。主题、配装变化或缓存被其他主题挤出后可后台回填。缓存锁不覆盖解码过程，保留最长边 512 像素、最多 72 项、约 48 MiB 像素预算及 LRU 淘汰。
5. **验证与交付基础**：增加统一验证脚本、Windows CI、SDK 版本约束、可选 Python 工具依赖版本和构建输出资源清单。资源清单记录每个文件的路径、大小、SHA-256 及类别；没有删除现有素材，也不将其视为素材授权证明或最小发行包。

被隔离的 `.rejected` 事件按修改时间保留最多 7 天、最多 128 个，约每小时清理一次。有效但被占用的事件文件保留待重试。事件目录整体扫描仍与积压规模相关，只是移出了界面线程；配置写入和原生窗口检查仍在界面线程，不能据此承诺所有卡顿已消除。

## 复现

在 Windows 项目根目录执行：

```powershell
# 无全局输入钩子、无个人配置、无音效的回归，供 CI 默认使用
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Validate.ps1

# 原生窗口、输入、排列及皮肤完整测试；会创建并操作测试窗口
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Validate.ps1 -FullDesktop
```

默认输出到 `artifacts/validation/<随机 ID>/`。需要 .NET SDK 10.0.102 或同一 feature band 中允许的更新补丁、Python 3.13；默认验证只使用 Python 标准库。图片生成和旧评测扫描等可选工具的依赖通过 `python -m pip install -r requirements-dev.txt` 安装。

运行中的旧管理器不会自动加载源代码修改；需在后续切换到新构建后生效。当前终端任务保持运行。
