## 公开发布前必须收尾

- [ ] **确定素材分发范围。** 按 `THIRD_PARTY_NOTICES.md` 中的分类逐项补足许可依据；其中仍有官方角色图、字标、参考官方美术加工的资源，以及未核实分发依据的内容。检查范围包括程序资源、文档图册、截图与 Git 历史。现有来源声明不代表已完成这项核查。本轮保留现有素材，未自行下架。
- [ ] **完成隐私与密钥审查。** 本轮扫描了当前候选文本中的常见密钥格式，以及历史中的敏感文件名，均未命中；没有完成全部 Git 历史内容扫描、所有密钥类型识别或图片 OCR。发布前还应审查截图中的窗口标题、路径、会话和私人信息。
- [ ] **整理本机信息与个人开发流程。** `scripts/monitoring/review-instructions.md` 包含本机目录和个人巡检安排；若作为公共工具发布，应改为通用示例。部分 `docs/**/validation.json`、存储评测和工具含本机路径，逐项判断保留必要性并脱敏。完整路径清单在本地 `source-audit.json` 中。
- [ ] **固定发行提交。** 工作区有大量未提交修改和未跟踪文件，其中包括 LICENSE、英文资源、品牌、文档和发布工具。逐项审查后提交，避免遗漏资源，也不要无差别加入个人产物。最后从该提交重新构建并生成证据。
- [ ] **做干净 Windows 环境验收。** 安装注明版本的 Desktop Runtime，从解压目录启动；检查缺运行库提示、中文与英文、主题图片、音效缺失时静音、窗口绑定/切换/恢复、右键关闭、长按拖动、正常退出、Terminal 配置备份与恢复。覆盖普通权限、至少两种缩放比例及多显示器。当前机器的构建与自检不能替代这一步。
- [ ] **补齐发布物与说明。** 确定预览版本号与 tag，打包 ZIP，生成 SHA-256，写明运行库、支持平台、启动程序名称、更新与回退方式、已知限制。现有源码版本 `0.1.1` 不代表已有同名正式发布。
- [ ] **在确定提交上跑远程 CI。** 当前有 Windows 工作流，但查询未见运行记录。现有统一脚本覆盖可靠性和监控测试；英文适配、皮肤与任务状态测试尚未全部纳入统一 CI，应补齐或作为发行前独立门槛记录。

## 可在预览版后持续完善

- 多显示器、DPI、焦点和快捷键冲突的兼容性覆盖。
- 完整社区皮肤包 SDK、更多 CLI 状态接入与交互打磨。
- Windows 代码签名、安装器、自包含包与自动更新方案。
- 英文贡献/FAQ/开发文档；目前英文首页可用，但部分深入文档仍为中文。
- 明确并启用私密漏洞报告渠道；当前安全说明提供的是条件式指引。
- 将源码与大体积演示素材的分发方式分开规划。当前 Git 跟踪文件及未忽略的新文件候选合计约 447.8 MiB；这是候选工作树文件大小，不是 Git 历史或下载压缩包大小。精简应用包约 200 MiB，主题资源占绝大部分。

## 建议发布顺序

先处理素材与隐私范围，整理并固定提交，再完成干净环境验收与远程 CI，最后生成带校验值的预览发行包、更新版本记录并公开发布。开发预览说明用于表达产品成熟度，不能替代以上发布检查。
