# 游戏套装与原生界面校准

[打开交互图库](index.html)。图库包含 13 套主题的 26 张轮盘装饰开关对照、13 张任务总览和 13 张配装窗口，共 52 张实际 WPF 截图。另直接展示 117 个透明实体的 64 px / 132 px 对照；素材来源、原始尺寸与生成方式见 [素材说明](../../skins/loadouts/suites-v1/README.md)。

内置选择按主题保存到 `EquipmentSelections`，旧 `EquipmentId` 保持为兼容基准。改变主题 A 的选择不会隐式改动尚未配置过的主题 B。自定义图片与名称继续保留，配装先编辑独立草稿，取消不会写回任务。编号、窗口绑定、项目、重连信息与实体外观相互独立。

轮盘、切换提示、任务总览与设置套装预览使用同一实体，保留各游戏的材质与克制的装饰。移除小按钮向外偏移以避开长枪和棍头；空槽继续使用淡加号。缺失或损坏素材会明确提示并使用兼容藏品。

这次实际检查发现并修复了短屏总览的布局循环：在 `ScrollViewer` 内用父级 `ActualHeight` 设置普通子图片高度，会因边框与边距每轮增长。实体插画现放在不参与期望尺寸计算的 Canvas 覆盖层，预览装饰不会再反过来撑大卡片。原有短屏原生缩略图与滚动用例修复后约 260 ms 完成。

显示缓存按最长边 512 px 解码，受 72 项 LRU 和 48 MiB 像素预算双重约束；原始资源及导入原图不因显示缓存而压缩。该预算仅指缓存中的像素表面，不代表整个进程的内存上限。设置中的静态预览页不再保留无用的 GIF 播放时钟，隐藏或关闭时停止播放并释放资源。

验证结果记录在 [validation.json](validation.json)：12 组配装验证、21 组皮肤验证、6 组设置工作室验证均通过。覆盖 13 套主题、装饰开关、320 / 360 / 480 DIP 命中位置、200% 显示缩放、短屏滚动、素材来源与完整性、草稿取消、主题独立选择、旧配置兼容与现有窗口绑定不变。

轮盘 180 帧绘制命令采样的中位数为 0.0849 ms、p95 为 0.1928 ms，平均分配约 14.6 KB / 帧。这是 UI 线程记录绘制命令的时间，未包含系统合成、实际窗口激活或截图编码，不能作为端到端切换延迟。

终端外观沿用已有精修资源。本轮没有打包，也没有改写当前 Terminal 配置。配套音效见 [主题音效](../game-audio/index.html)。
