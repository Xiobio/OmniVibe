这次校准解决的问题

  • 主题切换后自动使用对应游戏内容；每套主题的槽位选择独立保存，任务移动时继续跟随同一个任务。
  • 移除原先的终端首字标记。轮盘、配装、总览标识和设置预览共同使用同一实体。
  • 逐张清理图集中跨格的枪管、碎片与附属物，保留完整主体。没有以重复图片或单纯换色补数。
  • 保留轻量加号与淡化的移除按钮；长武器旁的移除目标向外偏移，避免挡住枪管或棍头。
  • 配装草稿取消不改变现有任务；自定义图片保留，素材缺失时有兼容回退。
