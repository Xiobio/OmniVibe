# 设置与首次使用

OmniVibe 把独立窗口收进编号槽位，用角色或武器帮助辨认，再用点击或快捷键找回。一个 Terminal 窗口里的多个标签页共用一个槽位；它们不是多个独立窗口。

## 第一次怎么用

1. 照常打开 CMD、PowerShell 或 Terminal。
2. 鼠标移入悬浮入口，点空槽的 **＋**，选择已有窗口；也可以把窗口标题栏拖到空槽。
3. 点击槽位形象进入窗口，或者使用快捷键。再按同一个窗口快捷键，会恢复唤出之前的状态。
4. 拖动任务形象可以排序；悬停后点右上角 **×** 只移出管理，终端继续运行。

首次启动且没有已有任务或历史时，会打开带示意图和实际操作按钮的引导。以后可从右键菜单的「快速上手」，或者设置的同名页面重新查看。引导显示当前已保存的按键；暂停、未设置或注册失败会明确提示。

| 默认按键 | 解决什么问题 |
| --- | --- |
| Alt + 1–9 | 找回某个编号窗口；再按恢复原样 |
| Alt + 滚轮 | 不打开菜单，直接切换任务 |
| Tab | 查看全部任务；滚轮选择，Enter / 点击进入，再按关闭 |
| Alt + Q | 按住，指向任务形象，松键进入 |
| Alt + 反引号 | 同时排列窗口，再按恢复原布局 |
| Ctrl + Alt + 空格 | 显示或隐藏悬浮入口 |

默认单独 Tab 会接管终端补全，可在快捷键页改为组合键或清除。这里的表格仅列默认值，改键后以应用内「快速上手」为准。入口隐藏后也可双击系统托盘中的 OmniVibe 图标找回。

## 五个设置入口

| 页面 | 内容 |
| --- | --- |
| 快速上手 | 三步示意、添加窗口、恢复任务、当前快捷键与常见问题 |
| 主题与换装 | 全部 13 个主题图片、整套效果预览、九槽形象陈列、界面效果 |
| 快捷键 | 点击并按键录入；逐窗口自定义、滚轮切换、清除与单项恢复默认 |
| 窗口与布局 | 排列方式、间距、唤出大小、收纳行为、入口范围与位置 |
| 常规 | 启动恢复方式、临时暂停、声音；维护工具默认收起 |

主题直接点图片选择，十套游戏主题优先陈列，右侧保留整套预览。点「角色与武器」可一次看到九个形象，为当前槽位选择；从设置打开时先返回设置草稿，点主窗口「保存并应用」才生效，取消不会改变当前配装。配套 Terminal 外观在明确标注的独立区域应用，会备份 Terminal 配置。

快捷键可使用自定义组合、功能键或单键，不再限于预设修饰键与数字。单键会全局接管原应用的相应输入，页面会显示这一影响。Esc 用于取消录入，Windows 保留组合和全局 F12 无法绑定；占用或重复时会指出具体操作。旧配置沿用原有修饰键与 1–9，已清除的按键不会在重启时被恢复。

原「更多」里的配装、暂停、位置与配置目录归入设置；右键菜单只保留即时操作、设置、恢复、引导与退出。启动恢复的三个开关合成一个模式选择，动效与装饰合成三档界面效果。
