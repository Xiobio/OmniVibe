# 七项交互修正

- Alt＋反引号排列和恢复时保留悬浮入口。旧的「排列时隐藏侧栏」配置迁移为关闭，仅主动隐藏才会隐藏入口。
- 槽位提示直接显示任务名、状态、项目和操作提示，不等待系统 tooltip 计时；内容随任务变化更新，提示不抢终端焦点。
- 展开后所有空槽常态显示清晰的「＋」和编号，左键点击即可选择已有窗口。保留拖入绑定。
- 关闭真实窗口后退出当前槽位，项目、会话、备注和配装保留在「最近关闭」。启动时遗留的已关闭窗口也会清理。
- 最近关闭保留最多 30 条记录，从「更多 → 最近关闭 / 恢复工作现场」进入。恢复使用空槽，保留原任务 ID。
- 悬停已有任务时右上方出现「×」，直接移出管理；总览卡片也增加「×」。移出后终端继续运行，不结束 CLI。
- 按槽位几何范围持续识别悬停，穿过透明图像的空隙不会丢失目标。离开整个操作区约 400 毫秒后收起；短暂移出再返回取消收起。
- 悬浮入口保持置顶；意外隐藏或最小化后恢复显示，尊重用户主动隐藏。窗口排列、恢复、悬停与展开均不改变任务编号或核心位置。

绑定单位仍是系统窗口，Windows Terminal 内部的标签页和分屏不是独立窗口。未被销毁但暂时无法验证身份的窗口仍保留重连能力。
