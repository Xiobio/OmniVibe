# 十套主题声音补齐与完整播放验证

补齐 DNF 与金铲铲后，十套游戏主题均有对应的窗口切换声音。三个经典主题仍支持用户导入，缺少素材时保持静音。界面和声音主题可以分别选择；「跟随界面」也会持久保存。

| 新增主题 | 实际音源 | 处理与来源边界 |
| --- | --- | --- |
| DNF | 鬼剑士「鬼斩」短语音，完整约 0.894 秒 | 来自 [DFQ-Original 固定版本](https://github.com/2DScrollGames/DFQ-Original/tree/d4b9088d9e6efeede3e504d3b6e64e3a459aa012)；技能配置、状态文件和播放代码明确关联鬼斩。标为社区项目收录，尚未独立比对正式客户端音库。 |
| 金铲铲之战 | 官方「小企鹅历险记」活动点击音，完整约 0.144 秒 | [官方活动](https://jcc.qq.com/act/a20230907guide/index.html)将独立点击音绑定到交互按钮。原片音量很轻，施加恒定增益至约 0.35 峰值；不冒称客户端升星音或角色语音。 |

[清单](../../skins/signature-audio/catalog.json)记录原始 URL、固定版本、源文件和输出文件 SHA-256，以及转换参数。新增两份音源经过独立重新下载、转换，输出与已安装版本哈希一致。音频留在本机缓存；仓库保存清单、安装工具和验证摘要，不提交第三方音频文件。

完整播放检查发现，原有 256 帧原生输出缓冲在本机设备上反复欠载，声音采样消耗耗时约为标称长度的 2.38 倍。现在采用原生缓冲完成事件与 1024 帧缓冲，每块约 23.2 毫秒，三块共约 69.7 毫秒；没有修改系统全局计时器精度。声音仍在后台线程播放，连续切换不会堆积无限队列，闲置 800 毫秒后释放设备。

验证使用真正的 `Manager.PlayCue`，将十套主题分别保存为显式声音主题与跟随界面主题，共二十次原生播放。检查实际文件、完整采样帧数、播放耗时和自然释放；不会刚打开设备就调用 Stop 来代替完整播放。音量为 0.1%，不操作真实终端。计时反映原生混音器采样消耗与设备生命周期，并非麦克风或回环录音，也不代替主观听感判断。

最终结果与实际证据路径见 [validation.json](validation.json)。

本机二十次检查全部通过。以相同的完整 PCM 比较，心之钢原先约 3.80 秒才消耗完采样，新版约 1.55–1.56 秒（文件标称 1.592 秒）；无畏契约约 2.76 秒（标称 2.8 秒），黑悟空约 2.97 秒（标称 3 秒）。这些数值允许最后至多约 70 毫秒已经排入设备的采样继续播放，因此不应把混音器结束时刻解释成扬声器最后一个采样的时刻。仅增加完成事件、仍保留 256 帧的对照也未通过，最终事件与较大缓冲组合才通过。

Debug 已正常重新构建并启动，置顶圆盘实际可见；五条近期任务恢复记录和原有偏好保留，Terminal 进程及配置未改变。本轮未重启终端会话。
