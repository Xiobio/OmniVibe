# Support image

`alipay.png` is the project author's supplied Alipay collection card, published at their request for voluntary support.

The supplied JPEG was cropped at `(230, 850, 1250, 1390)` in its original 1708 × 2560 pixel coordinates and saved as PNG without resizing, retouching, or regenerating the QR code. The complete code, original quiet zone, avatar, and recipient label are retained. No original full-size poster is duplicated in the repository.

This payment image is not part of the project's MIT-licensed code or reusable theme artwork. Do not reuse it as an example payment destination in forks; replace it with your own verified support information or remove the funding link.
