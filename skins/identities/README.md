# Empty theme identity

When no window is bound, the dock core and overview's empty card show a theme-specific original miniature companion or device. All thirteen themes have independent transparent artwork. No game names, official logos or existing game characters are used in the active empty-state collection. Binding a task restores its chosen weapon or character; removing the last task restores the original companion. This is independent of all nine equipment assignments.

`catalog.json` maps every theme slug to one `*-original-v3.png`, its original name, dimensions, alpha coverage, SHA-256 and complete prompt. Thirteen separate built-in imagegen requests generated the original companions with real alpha, without reference images. The raw PNGs are copied unchanged. Prompts are in [original-v3.prompts.md](original-v3.prompts.md). Older wordmarks and covers are historical source/comparison files and are not referenced by the active manifest; their attribution remains applicable to those older files.

For custom theme packs, provide one PNG with real alpha and a `file` entry with a filename in this directory. At least 12% of decoded pixels must be nearly transparent and at least 3% substantially opaque. Fully opaque posters, rounded app tiles with only corner transparency, and blank images are rejected. The app fits the complete silhouette without a rectangular clip, freezes a decoded copy with longest edge capped at 512, and never reads files during dock drawing. No slideshow, timer or background animation is started for an empty dock. Use an isolated recognizable character or game mark; avoid scene backgrounds and backplates.

If an identity image is unavailable or fails the alpha check, the app uses the existing transparent native core art. Missing identity artwork never changes task bindings or capture hit targets. Empty cores retain a quiet themed “拖入窗口” cue, which changes to “松手收纳” over a valid target. No detached plus badge is placed on the companion.

Overview size is available at **设置 → 窗口与布局 → 任务总览大小**. Five saved presets are provided: 紧凑、标准、宽敞、超大、近全屏. The default is 超大. Size is constrained in logical pixels to the current work area, keeping visible desktop margins; short screens retain scrolling and keyboard navigation.
