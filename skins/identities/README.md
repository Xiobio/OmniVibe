# Empty theme identity

When no window is bound, the dock core and overview's empty card show a transparent game wordmark or character silhouette. This is separate from all nine saved equipment assignments. Binding a task restores its chosen weapon or character; removing the last task restores the game identity. Empty wheel targets retain their quiet plus marks and fixed numbers.

`catalog.json` maps each game theme slug to one local image, source page, dimensions and SHA-256. Wordmarks are unchanged official-site transparent images. The Wukong cutout is an AI-assisted extraction from the promotional cover; its reference and full prompt are recorded separately. Earlier opaque covers remain as source/comparison files and are not rendered by the identity system. Game art and trademarks remain the property of their respective rights holders; these assets are not covered by OmniVibe's source code license. This is not an official game product.

For custom theme packs, provide one PNG with real alpha and a `file` entry with a filename in this directory. At least 12% of decoded pixels must be nearly transparent and at least 3% substantially opaque. Fully opaque posters, rounded app tiles with only corner transparency, and blank images are rejected. The app fits the complete silhouette without a rectangular clip, freezes a decoded copy with longest edge capped at 512, and never reads files during dock drawing. No slideshow, timer or background animation is started for an empty dock. Use an isolated recognizable character or game mark; avoid scene backgrounds and backplates.

If an identity image is unavailable or fails the alpha check, the app uses the existing transparent native core art. The three original ink themes use that fallback deliberately. Missing identity artwork never changes task bindings or the capture hit targets. The gray Genshin wordmark takes the theme's accent through a runtime opacity mask for legibility; the source file remains unchanged.

Overview size is available at **设置 → 窗口与布局 → 任务总览大小**. Five saved presets are provided: 紧凑、标准、宽敞、超大、近全屏. The default is 超大. Size is constrained in logical pixels to the current work area, keeping visible desktop margins; short screens retain scrolling and keyboard navigation.
