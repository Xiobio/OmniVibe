## 素材身份与来源

11 套新器物／棋灵包通过内置 `image_gen.imagegen` 制作透明九实体图集，再按 alpha 连通区域与网格质心分配独立实体。它们是 **AI 辅助原创风格演绎**，不是官方游戏皮肤、游戏道具截图或官方合作素材。角色、游戏名称及相关权利属于各自权利人。每套的完整提示词、源图哈希和源分辨率记录在 `prompts.json` 与 `catalog.json` 的 `generation` 中。

无畏契约使用 Riot Games 原游戏特工图像，经 [Valorant-API](https://valorant-api.com/) 社区镜像提供；对应角色可在 [官方特工目录](https://playvalorant.com/en-us/agents/) 核对。`source` 是实际下载地址，`sourcePage` 是官方角色页面，`sourceSha256` 是下载原件哈希。原游戏图像的版权属于 Riot Games，**不因本仓库代码开源而获得代码许可证授权**。

永劫无间复用 `../naraka/characters-v2` 中现有的高清角色演绎。它们参考网易官方角色立绘，经内置 imagegen 转成透明持械立绘；不冒称为未加工的官方原图。`source` 保留最初的官方参考地址，`sourceSha256` 对应仓库中复用的既有生成原图。角色权利属于网易。

## 新内容包约定

1. 在 `catalog.json` 对应主题的 `items` 中提供 **恰好 9 项**，每项具有稳定且唯一的 `id`、可识别的 `name`、`kind`、`image`、`source` 和 `provenance`。主题通过 `skin` 枚举匹配，避免依赖显示名称。
2. `image` 相对于本目录，只能引用目录内部文件，不能包含 `../` 或绝对路径。推荐 `主题slug/稳定id.png`。原有永劫 `katana` 等 ID 保留兼容已有配装。
3. 使用真实透明 RGBA PNG。不要把棋盘格绘进图片，不带方形背景板、文字或多余圆环；单个主体完整，四周至少留 12 个透明像素。附件、飘带和粒子应属于该实体，不能混入相邻格的碎片。
4. 主体在 56px 槽位与 110px 核心都要能辨认。角色图推荐原生长边 1024–1536px；器物也可使用约 300–500px 的真实绘制内容。**不得把透明画布大小或后期放大尺寸当成原生细节分辨率**。
5. 本包器物沿用原生图集像素，仅提取完整轮廓并补透明边，不进行放大。`sourcePixels`、`nativeContentPixels` 和验证记录用于区分原始像素与画布。角色包仅做高质量缩小。
6. 替换九张实体图即可形成新的内容包；全局主题的配色、装饰、动效与音效仍由主题系统提供。自定义单个槽位图片仍独立于内容包，不会被切换主题覆盖。

## 制作与验证

`tools/build-suite-assets.py` 保存图集提取与校验流程。示例：

```powershell
python tools/build-suite-assets.py --slug hextech --source path/to/transparent-atlas.png --prompt-file path/to/prompt.txt
python tools/build-suite-assets.py
```

每次提取先在整张图集识别 alpha 主体，再按质心归入对应格；这样可保留伸过名义网格的剑尖，并去掉相邻格残片。它不是简单地把图集硬切九块。脚本检查 13 套数量、每套九个唯一文件哈希、透明度、非空主体、尺寸与来源说明，并输出 56px／110px／大图三档联系表。**程序检查不能代替目视验收**；每一套还需看轮廓、附件、串格、裁断、实际窗口显示及装饰关闭时的可读性。

原图和联系表在开发证据 `artifacts/suite-assets/`，交付 PNG、完整提示词、来源信息和校验结果保存在本目录。源图集不重复提交，以控制仓库体积。
